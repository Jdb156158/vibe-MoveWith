# 网页验收记录

## 本地验收

- 桌面 1440 × 1100：五项交互通过，页面无 JavaScript 异常。
- 触屏 390 × 844：真实 touchStart / touchMove / touchEnd 拖动通过。
- 320 像素窄屏：五种面板无横向溢出，截图人工检查。
- 看板：拖到目标列后，卡片位置和三列计数同步；左右键移动通过。
- 响应式预览：390px 单列、800px 双列，拖动手柄同步宽度与布局。
- 关系网：节点拖动、连线跟随、松手回弹到原位，直接关系数量正确。
- 回收站：有效投放后隐藏文件并增加计数；撤销恢复；Delete 键回收通过。
- 浮窗：缩小、拖动、左上角吸附，循环视频保持播放、无媒体错误。
- 完整 AI 提示词复制通过。
