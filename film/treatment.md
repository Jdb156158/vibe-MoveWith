# 拖动，让意图落地 / Move with intent

20 秒，1920×1080，60fps。沿用系列黑色 Bento：五项总览 → 大卡逐项展示 → 全部归位。无旁白；原创音乐与音效。

## 来源核实（2026-10-26）

下列为源站目录和实际 HTML/JS 演示核实的交互机制；本片独立 Canvas 重绘，显示的任务、文件、内容均是教学示例。没有统计数据或效果提升比例。

|项目|出处|核实机制|本片展示|
|---|---|---|---|

|响应式预览|https://lucianlabs.dev/uxui-prompt/#257|拖动边缘改变宽度，卡片换列，导航折叠，断点提示|宽度 1200 → 390，3 列变 1 列，菜单折叠|

|拖拽回收|https://lucianlabs.dev/uxui-prompt/#315|接近时桶盖打开，松手缩入，计数变化，可撤销|文件拖入回收站，数量 +1，再点撤销归位|

同类型定义：直接拖动对象改变其位置、尺寸或状态。与此前按钮、导航、3D 旋转及图表选题不重复。

## 视觉方向

沿用已接受的 Bento 分区和橙粉紫片名；控件分别用蓝、紫、青绿、珊瑚橙、淡蓝。主体区域宽 1160px，左侧固定显示用途和提示词。指针按下时出现环，拖动期间保持按住，松手后显示落点反馈。

场景数据只用说明机制所需的最小集合；指针拖动方向必须与对象运动方向一致。

## 节奏与时间码

120 BPM，2/4 拍；首拍 0 秒，小节 1 秒。所有章节在小节线上。20 小节 / 10 个双小节乐句，18 秒终止和弦，末尾 0.8 秒淡出。

|时间|画面 / 动词|场景|AI 提示词|音效|
|---|---|---|---|---|
|0–2|五个控件同屏，卡片进入格位；标题 Move with intent.|总览|5 种拖拽交互|开场低鼓、卡片定位声|
|2–5|抓起任务→拖入下一列→落位更新计数|任务管理|做拖拽看板，目标留位，松手更新计数。|拾起、拖动风声、落位提示|
|5–8|拖窄右边界→卡片换列→导航折叠|适配检查|做响应预览，拖动改宽，断点自动换列。|拖动轻噪、断点提示|
|8–11|拉节点→连线跟随→松手回弹|关系探索|做弹性关系网，节点跟手，松手平稳回弹。|拉伸音、回弹提示|
|11–14|拖文件→开盖收纳→点击撤销归位|文件整理|做拖拽回收，靠近开盖，删除支持撤销。|开盖、收纳、撤销确认|
|14–17|视频缩成浮窗→拖向另一角→吸附|边看边用|做吸附浮窗，拖动跟手，松手贴近角落。|缩小、移动、吸附|
|17–20|五项归位；场景＋动作＋反馈|总结|让每次拖动，都有明确落点。|归位和弦、尾音淡出|

每项有两个动作阶段和结果停留。11 秒“删除后，还能反悔。”用撤销反馈承接注意力；14 秒由任务小物切换到视频浮窗，形成动静对比。

## 连续性

总览任务卡 → 同一任务卡放大；任务落位 → 预览框缩放；布局断点 → 关系节点连线；节点归位 → 文件归位；回收撤销 → 浮窗吸附；浮窗缩回 → 总览重新排齐。

## 验收计划

先做最难的响应式重排和浮窗吸附，检查 9 个关键时刻（0、3.1、4.3、6.2、7.4、9.4、12.5、15.8、19.2）并至少修订两轮。检查转场后的第一秒。最后逐帧 JPG、H.264 Main yuv420p + AAC faststart，检查最终 MP4 抽帧、完整播放、跳转、音频峰值，交付源代码 ZIP。
